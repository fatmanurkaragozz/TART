# Katkıda Bulunma

TART'a ilgi gösterdiğiniz için teşekkürler! Katkılarınızı memnuniyetle karşılıyoruz.

## Hata bildirimi / Özellik talebi

[Issues](../../issues) sekmesinden yeni bir issue açın. Hata bildirimi ve özellik talebi için hazır şablonlar mevcuttur; mümkünse bunları kullanın.

## Kod katkısı

1. Depoyu fork'layın ve yeni bir branch açın.
2. Kurulum adımları için [README.md](README.md) (Türkçe) veya [README.en.md](README.en.md) (English) dosyasındaki "Kurulum Kılavuzu" / "Setup Guide" bölümünü takip edin.
3. Değişikliğinizi açıklayan bir pull request açın.

## Davranış

Saygılı ve yapıcı bir iletişim bekliyoruz — TART'ın kendisinin de savunduğu "sağlıklı eleştiri kültürü" ilkesiyle tutarlı şekilde.

# Contributing

Thanks for your interest in TART! Contributions are welcome.

## Bug reports / Feature requests

Open a new issue from the [Issues](../../issues) tab. Templates are available for bug reports and feature requests — please use them when applicable.

## Code contributions

1. Fork the repo and create a new branch.
2. Follow the "Setup Guide" section in [README.en.md](README.en.md) (English) or [README.md](README.md) (Türkçe) for setup instructions.
3. Open a pull request describing your change.

## Conduct

We expect respectful, constructive communication — in line with the "healthy culture of criticism" TART itself is built around.
